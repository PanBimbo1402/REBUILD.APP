# REBUILD Core 0.5 — Health + Training Foundation

Draft features added in this version:
- New-user PR questions for bench, squat, deadlift and fastest mile.
- Approximate starting-weight suggestions from entered PRs (conservative, editable, not a guarantee).
- Strength logger keeps the 0.4 set/weight/reps workflow.
- Rest timer now has Start, Stop and Reset controls.
- Training has Strength, Cardio and Running subsections.
- Running sessions can be logged manually now; Apple Watch/HealthKit is deliberately marked as future work.
- Nutrition section with macro rings and a food log.
- Add Food popup offers nutrition-label photo, barcode, estimate and manual entry flows.
- Photo AI extraction and live barcode-product lookup are UI prototypes only until a secure hosted backend/API is added.
- Manual sleep logging produces a compact, non-diagnostic training note.
- Existing day timeline, work alignment, schedule editor and exercise form popup remain.

This is still a navigator/prototype draft, not the final architecture.
